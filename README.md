# 생활비 캘린더

Galaxy S23~S26에서 개인적으로 사용할 오프라인 생활비 관리 앱입니다.

현재 단계는 앱 시작 시 문자 자동 업데이트·중복 방지와 월간 캘린더 대시보드의 기본 흐름을 실제 Galaxy 기기에서 검증하는 MVP 개발 버전입니다.

## 현재 구현

- Android 13(API 33) 이상 지원
- Android 16 QPR2(API 36.1) SDK로 컴파일
- `READ_SMS` 런타임 권한 요청
- 대시보드에 표시된 달의 SMS와 MMS를 함께 조회
- 승인·취소·결제 관련 기본 문장이 있는 결제 후보 추출
- `로카 X 세라젬`, `[롯데카드]` → 롯데카드 식별
- `LGU+ M Ed3(통할2.0)`, `[현대카드]` → 현대카드 식별
- 롯데·현대카드 승인/취소 금액, 가맹점, 거래 시각 파싱
- `06월 이용 하이패스 27건 60,290원, 07월 02일 승인` 형태의 합산 승인 파싱
- 전달 문자 `보낸사람` 메타 줄 제거와 한국어 오전/오후 시각 파싱
- `현대카드 M` 형식 추가 식별
- 멤버십 혜택·결제대금·가입 안내 등 비거래 문자 후보 제외
- Room 로컬 DB 저장과 메시지 fingerprint 기반 중복 방지
- 월 이동과 좌우 스와이프를 지원하는 7열 캘린더
- 날짜별 순지출 합계와 선택 날짜 거래 목록
- 월 화면 최하단 카테고리별 순지출 가로 막대 그래프
- 월 예산·지출·남은 금액·사용률 표시 및 예산 변경
- 남은 금액과 사용률에 월 입금 반영 (`예산 + 입금 - 지출`)
- 선택 날짜 수동 지출 입력
- 수동 거래의 지출·입금 유형 선택
- 수동 거래의 현금·카드 결제수단 선택
- 팝업 입력란의 둥근 배경형 스타일과 금액 입력 중 천 단위 쉼표 표시
- 수동 카드 거래에서 등록된 카드 선택 및 해당 카드 실적 반영
- 월 입금 합계와 날짜별 입금 내역 분리 표시
- 카드 프로필 추가·삭제
- 카드별 식별 문장 추가·삭제
- 저장된 식별 문장을 사용하는 동적 카드 판별
- 카드별 실적 구간과 구간별 할인·캐시백 금액 추가·삭제
- 카드별 실적 제외 문장 추가·삭제
- 현대카드 기본 실적 제외 문장으로 `건강보험공단`, `LG유플러스통신` 등록
- 승인·취소·제외 규칙을 반영한 월간 인정 실적 계산
- 현재 혜택과 다음 구간까지 남은 금액을 표시하는 가로 실적 바
- 카드 실적 카드에 인정 실적과 총 이용금액을 함께 표시
- 실적 카드 선택 시 해당 월 이용내역을 최신순으로 표시
- 카드 실적 이용내역을 길게 눌러 거래 전체 수정 및 실적 즉시 재계산
- 메인·관리·실적 상세 화면의 슬라이드·페이드 전환
- 카테고리 추가·삭제와 가맹점 문구별 자동 분류 규칙
- 신규 거래 및 기존 기타 거래 자동 분류
- 거래 길게 누르기로 분류 설정 또는 삭제
- 거래를 눌러 가맹점·금액·날짜·유형·결제수단·카드·카테고리·상태·메모 수정
- 기존 카테고리와 별도로 `생활비`·`고정비`·`진영 용돈` 상위 분류 관리
- 문자·수동 내역의 상위 분류 기본값은 `생활비`, 거래 수정에서 변경 가능
- 월 화면 하단에 상위 분류별 지출 막대그래프 표시
- 거래별 카드 실적 `자동`·강제 `포함`·강제 `제외` 설정
- 거래를 길게 눌러 전체 수정·분류 규칙·삭제 작업 선택
- 삭제한 SMS 거래의 재가져오기 방지
- 설정 월 이후로 월 예산 자동 승계
- 데이터 변경 및 앱 백그라운드 전환 시 SQLite 스냅샷 자동 백업
- 주 백업과 직전 백업을 함께 보관하고 손상 시 직전 백업으로 복구
- 재설치 첫 실행에서 공용 저장소 백업 자동 감지·복원
- 인터넷 권한 미사용

## 빌드

Android Studio에서 `ExpenseCalendar` 폴더를 열고 Gradle Sync 후 실행할 수 있습니다. PowerShell에서는 아래 스크립트로 단위 테스트와 APK 빌드를 함께 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

테스트를 생략하고 APK만 다시 만들려면 다음을 사용합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipTests
```

생성되는 APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Galaxy 기기에 설치

1. 휴대전화에서 개발자 옵션과 USB 디버깅을 켭니다.
2. USB로 PC와 연결하고 휴대전화에 표시되는 디버깅 허용 창을 승인합니다.
3. 다음 명령으로 연결을 확인하고 APK를 설치합니다.

```powershell
C:\Users\dg479\AppData\Local\Android\Sdk\platform-tools\adb.exe devices
C:\Users\dg479\AppData\Local\Android\Sdk\platform-tools\adb.exe install -r -g .\app\build\outputs\apk\debug\app-debug.apk
```

4. `생활비 캘린더`를 엽니다.
5. 앱을 다시 실행해 현재 월 SMS·MMS가 자동 업데이트되고, 이전 월로 이동하면 해당 월도 자동 동기화되는지 확인합니다.

`READ_SMS`는 hard-restricted 권한입니다. 권한이 계속 거부되면 앱 화면과 설치 명령의 결과를 확인해야 합니다.

## 데이터 백업과 복원

- 백업 위치: `내 파일 > 내장 저장공간 > Documents > ExpenseCalendar`
- 현재 백업: `expense-calendar-backup.db`
- 직전 백업: `expense-calendar-backup.previous.db`
- 앱을 삭제해도 공용 Documents 폴더의 백업 파일은 유지됩니다.
- 재설치 후 앱이 표시하는 `저장소 권한 설정`에서 접근을 허용하면 기존 백업을 자동 복원합니다.
- Android 보안 정책상 재설치 후 저장소 접근 권한은 한 번 다시 허용해야 합니다.

백업 파일에는 결제 내역, 예산, 카드 및 분류 설정이 포함되므로 외부에 공유하지 않습니다.

## 개인정보

- 앱 manifest에 `INTERNET` 권한을 선언하지 않았습니다.
- 파싱된 결제 정보는 앱 DB와 공용 Documents의 로컬 백업 DB에 저장하며 문자 원문은 보관하지 않습니다.
- 메시지 fingerprint는 중복 판별에만 사용합니다.
- 로그에도 문자 원문을 출력하지 않습니다.
